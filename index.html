Matsuro Nihonshi Uploader

YouTube チャンネル「末路の日本史」の運営者が、自分で制作した動画を自分のチャンネルにアップロードするためだけに使う個人用のツールです。YouTube Data API を使い、動画のアップロード・公開設定・再生リストへの追加を行います。運営者以外の利用者はいません。

English

Matsuro Nihonshi Uploader is a personal tool used only by the operator of the YouTube channel "末路の日本史" (Matsuro no Nihonshi) to upload videos the operator produced to the operator's own channel. It uses the YouTube Data API to upload videos, set their visibility, and add them to playlists. There are no users other than the operator.
